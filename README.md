# GeoDiscoCats

Geographic Discovery of Cats - A statistical analysis project.

## Hypothesis Testing Notebook

The `hypothesis_tests.ipynb` notebook demonstrates statistical hypothesis testing techniques using synthetic geographic cat discovery data.

### Running the Notebook

This notebook is compatible with:
- **Deepnote** - Import directly or clone the repository
- **Modal** - Use Modal's notebook environment
- **Jupyter** - Run locally with `jupyter notebook`
- **Google Colab** - Upload or connect to GitHub

### Tests Included

| Test | Purpose |
|------|---------|
| One-Sample T-Test | Compare sample mean to expected population mean |
| Two-Sample T-Test | Compare means between two independent groups |
| Chi-Square Test | Test independence of categorical variables |
| One-Way ANOVA | Compare means across multiple groups |
| Pearson Correlation | Test linear relationship between variables |
